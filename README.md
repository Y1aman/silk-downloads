# سِلْك — التنزيلات الرسمية

برنامج مجاني مغلق المصدر لـWindows x64. هذا المستودع للصفحة والتنزيلات والوثائق العامة؛ شيفرة تطبيق سِلْك غير منشورة هنا.

- الموقع: https://getsilk.netlify.app/
- الإصدار التجريبي الحالي: [سِلْك 0.4.11](https://github.com/Y1aman/silk-downloads/releases/tag/v0.4.11)
- [دليل Windows وربط الوكلاء](https://github.com/Y1aman/silk-downloads/releases/download/v0.4.11/README-Windows.md)
- [ملاحظات الإصدار](https://github.com/Y1aman/silk-downloads/releases/download/v0.4.11/RELEASE-NOTES.md)
- [بصمات التنزيل](https://github.com/Y1aman/silk-downloads/releases/download/v0.4.11/SHA256SUMS.txt)
- [البلاغات العامة](https://github.com/Y1aman/silk-downloads/issues)

يدعم Codex للقراءة والتعديل في مساحة Git مستقلة، وGitHub Copilot CLI للقراءة والمراجعة، مع إسناد وربط يدوي للمهام وتسليم النتائج المقبولة. يحتاج كل وكيل أداته الرسمية وحساباً مؤهلاً؛ لا تشمل الحزمة اشتراكاً بالنماذج. اتصالات ACP الأخرى للحفظ والفحص فقط. التوزيع الآلي وربط Claude والكتابة عبر ACP غير متاحة بعد.

الحزمة تجريبية وغير موقّعة رقمياً، واختُبرت على جهاز Windows الحالي فقط. قارن بصمة الملف مع SHA256SUMS.txt، واقرأ دليل الاستخدام والخصوصية والترخيص المرفقين. لا تُرفق بيانات اعتماد أو قواعد بيانات أو نسخاً احتياطية أو محتوى مشروع خاص في البلاغات العامة.
