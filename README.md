# سِلْك

مساحة محلية لإدارة مشاريع ومهام وكلاء البرمجة. مجاني ومغلق المصدر.

هذا المستودع مخصص لصفحة التعريف والتنزيلات وملاحظات الإصدارات فقط؛ لا يحتوي مصدر تطبيق سِلْك.

توجد ملفات Windows التنفيذية في Releases. متطلبات التشغيل وحدود النسخة موضحة في صفحة التنزيل وملاحظات الإصدار. ربط Claude غير متاح بعد.

إشعارات المكونات المستخدمة في الصفحة: ترخيص الخط في docs/assets/OFL.txt وترخيص الأيقونات في ICON-LICENSE.txt.
