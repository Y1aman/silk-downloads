# سِلْك 0.4.7

إصدار تجريبي لـWindows x64. مجاني ومغلق المصدر.

## الجديد

- حزمة توزيع مستقلة، خالية من مشاريع المطوّر وبياناته ومسارات جهازه.
- فصل ملفات التوزيع عن ملفات البناء والحزم الشخصية.
- فحص محتويات الحزمة وإرفاق إشعارات المكتبات وبصمات SHA-256.
- إصلاح بدء التشغيل عندما يتعذر الوصول إلى مجلد «المستندات».

## متاح في هذا الإصدار

- إعداد التشغيل الأول واختيار مجلد المشروع وفحص Codex وGit.
- تشغيل مهام Codex بعد الموافقة ومراجعة النتائج قبل قبولها.
- إدارة المشاريع وملفات الوكلاء وحفظ البيانات محلياً.

## متطلبات الاستخدام

يشمل سِلْك محرك تشغيله ولا يحتاج إلى تثبيت Node.js لتشغيل التطبيق. لتشغيل مهام Codex، ثبّت نسخته الرسمية المستقلة لـWindows وسجّل الدخول بحسابك. Git مطلوب لمهام تعديل الملفات في مساحة مستقلة. تتصل طلبات النماذج بمزوّدها عبر الإنترنت وتستخدم حدود حسابك.

## حالة التحقق

نجحت 42 من اختبارات التطبيق والبناء، إضافة إلى فحص الحزمة والتشغيل والحفظ وإعادة الفتح في بيئة مستخدم معزولة على جهاز التطوير نفسه. لم يُنفّذ اختبار على جهاز Windows آخر بعد، ولم يُختبر المثبّت بتثبيت فعلي على جهاز آخر.

الحزمة غير موقعة رقمياً. ربط Claude غير متاح بعد.
