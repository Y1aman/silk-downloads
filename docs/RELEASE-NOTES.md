# سِلْك 0.4.10 — ربط الوكلاء والتنسيق اليدوي

نسخة تجريبية لـWindows x64، مجانية ومغلقة المصدر.

- ربط GitHub Copilot CLI عبر ACP لمهام القراءة والمراجعة، إلى جانب Codex للقراءة والتعديل في مساحة Git مستقلة.
- اختيار وكيل المهمة وتغيير إسناد الاقتراح، وربط المهام وتسليم النتائج المقبولة إلى المهمة التالية من الواجهة. لا تشغيل أو توزيع تلقائي.
- تصدير بيانات سِلْك واستعادتها مع معاينة ونسخة أمان، ودعم صيغ النسخ الاحتياطي 1 و2 و3. لا تشمل ملفات المشاريع أو تسجيلات الدخول.
- لوحة استهلاك حسب المشروع والوكيل والنموذج والفترة، مع تمييز الأرقام غير المتاحة من الصفر.
- فحص التحديثات وتنزيلها يدوياً، والتحقق من الحجم وSHA-256، ونسخة أمان قبل فتح المثبّت. فعّل تضمين الإصدارات التجريبية لتلقي هذه القناة.
- تحسين التعافي من الانقطاع والإلغاء وإعادة المحاولة، ومراجعة الأمان، والنصوص العربية والتنقل بلوحة المفاتيح والواجهة المدمجة.
- أدلة موحّدة للاستخدام والخصوصية والترخيص والبلاغات، وإشعارات تراخيص المكونات.

يتطلب كل وكيل أداته الرسمية المثبتة وحساباً مؤهلاً. لا تضم الحزمة Codex أو Copilot أو اشتراكاتهما. قد تكون خطة Copilot المتاحة محدودة بالنموذج Auto. اتصالات ACP الأخرى قابلة للحفظ والفحص، لكن تنفيذها والكتابة عبر ACP وربط Claude غير متاحة بعد.

نجح البناء واختبارات المصدر الـ90، واختبار تنسيق فعلي من الواجهة بين Codex وCopilot على جهاز Windows الحالي. فُحص عرضا 1280 و390 بكسل. لم يتوفر جهاز مستقل للاختبار. ملفات Windows تجريبية وغير موقعة رقمياً؛ البصمات المنشورة تتحقق من تطابق الملف ولا تمثل توقيع ناشر.

مستخدمو 0.4.8: نزّلوا هذا الإصدار من الموقع مرة واحدة، واستخدموا مسار التثبيت الحالي. بيانات سِلْك محفوظة خارج ملفات البرنامج؛ لا تحذفوا مجلد البيانات أثناء الترقية. ملف README-Windows.md يشرح ربط Copilot والنسخ الاحتياطي والتحديثات.
