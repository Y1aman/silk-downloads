# سِلْك 0.4.14 — عرض الصور في المحادثة

نسخة تجريبية مجانية مغلقة المصدر لـWindows x64.

- تظهر الصور الجديدة أو المعدلة من نسخة مهمة المجلد مباشرةً في نتيجة المحادثة، مع تكبير الصورة وتنزيلها.
- تدعم المعاينة PNG وJPEG وWebP وGIF، حتى 12 صورة لكل مهمة و10 ميغابايت للصورة. تُعرض الصور الفعلية فقط بعد التحقق من محتواها، ولا تُعرَض الملفات غير المعدلة أو الملفات خارج نسخة المهمة.
- تظهر صور المهام السابقة إذا بقيت نسخة عملها المحلية متاحة.

- خيار «تعديل في نسخة مجلد» دون مستودع Git أو حفظ أولي، وهو المسار المقترح افتراضياً لتعديلات الملفات في المحادثة.
- يعدّل Codex نسخة مستقلة، ويبقى المشروع كما هو حتى مراجعة الملفات والموافقة على تطبيقها.
- عرض محتوى الملفات قبل التعديل وبعده، بما يشمل الملفات الجديدة والمحذوفة، وخيار استعادة الملفات السابقة بعد التطبيق.
- يمنع التطبيق والاستعادة فوق تغييرات أحدث، ويطلب مراجعة جديدة إذا تغيرت نسخة التنفيذ بعد عرضها. يحفظ سجل استعادة قبل الكتابة للتعامل مع الانقطاع.
- Git خيار إضافي لمساحات Git المستقلة؛ لم يعد شرطاً لتعديل الملفات في نسخة مجلد.
- النسخ الاحتياطية تدعم الصيغ 1 إلى 4؛ تُستخدم الصيغة 4 عند وجود مهام مجلدات. نسخ ملفات العمل وسجلات الاستعادة تبقى محلية ولا تشملها ملفات تصدير بيانات سِلْك.

حدود نسخة المجلد: حتى 20 ألف ملف و256 ميغابايت، باستثناء .git وnode_modules و.venv و__pycache__. لا تُنسخ الروابط الرمزية. المراجعة تعرض حتى 150 ألف حرف؛ الملفات الثنائية والكبيرة تحتاج مراجعة نسختها المحلية. الاستعادة تخص محتوى الملفات ولا تحفظ المجلدات الفارغة أو الأذونات المخصصة. تبقى نسخ العمل محلياً وتستهلك مساحة إضافية. هذا المسار لا يضيف توليد الصور أو قدرات جديدة للمزوّد؛ يحتاج التنفيذ أداة الوكيل الرسمية وحساباً مؤهلاً وعزله المحلي.

نجحت الاختبارات الـ99، وفحص الواجهة على الحاسوب والهاتف، واختبار فعلي مع Codex لتعديل ملف في مجلد بلا Git ثم تطبيقه واستعادته. اختُبر على جهاز Windows الحالي فقط. الملفات غير موقّعة رقمياً؛ بصمات SHA-256 للتحقق من تطابق الملفات.

صفحة البداية الجديدة وربط Copilot للقراءة والمراجعة والتنسيق اليدوي والميزات السابقة مضمّنة. لم يُنفذ ربط Claude أو التوزيع الآلي أو الكتابة عبر ACP.

حدّث من الإعدادات مع تفعيل تضمين الإصدارات التجريبية، أو نزّل الملف من الموقع. مستخدمو 0.4.10 يحتاجون التنزيل اليدوي مرة واحدة بسبب عطل التحديث في تلك النسخة.
